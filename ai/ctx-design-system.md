### Design system — single source of truth

Все стили подчиняются нескольким простым правилам. Цель — чтобы
любая новая страница (FAQ, блог, отзывы, любая будущая) **наследовала**
существующий язык, а не выдумывала свой.

Прежде чем верстать страницу — найдите подходящий shared-компонент.
Если его нет, добавьте в `shared/components/ui/` и переиспользуйте на
других страницах.

### Цветовые токены

Источник: `apps/web/src/shared/constants/tokens.ts` (`SUB0`).

| Токен        | Hex       | Где использовать                                    |
| ------------ | --------- | --------------------------------------------------- |
| `blue`       | `#1347ff` | акценты, активные состояния, ссылки CTA, селект     |
| `ink`        | `#0a0a0a` | основной текст, чёрный фон логотипа, primary-кнопка |
| `bg`         | `#fafaf7` | фон страницы (cream), фон тёмных секций hero        |
| `panel`      | `#ffffff` | фон контентных секций, карточек                     |
| `line`       | `#e9e7df` | бордеры, разделители                                |
| `line2`      | `#eeece3` | вторичные бордеры                                   |
| `muted`      | `#6b6b66` | приглушённый текст, label, хлебные крошки           |
| `soft`       | `#f2efe6` | подложка под info-блоки, sidebar-active             |
| `danger`     | `#c94a1c` | ошибки, отрицательные состояния                     |
| `good`       | `#0a7a3f` | success                                             |
| `warn`       | `#b0851a` | warning                                             |
| `purple`     | `#6b21d9` | редкие акценты (например, badge)                    |

`::selection` подсвечивается `SUB0.blue` — это в `globals.css`,
никогда не переопределять.

Тёмная тема — пока не реализована. Когда дойдём до неё, токены
переедут в CSS-переменные через `next-themes`. До этого — только
светлая.

### Шрифты

Подключены в `app/layout.tsx` через `next/font/google`:

- **Inter Tight** (`400/500/600/700/800`, latin + cyrillic) — дефолтный
  для всего. `body` уже использует его. Ничего ручного добавлять не
  нужно — просто не указывайте `fontFamily`.
- **JetBrains Mono** (`400/500/600/700`, latin + cyrillic) — `var(--font-mono)`,
  через токен `mono` из `tokens.ts`. Только для:
  - eyebrow-меток (см. `SectionEyebrow`),
  - хлебных крошек,
  - чисел в нумерации FAQ-вопросов,
  - email-адресов в footer/hero,
  - код-снипетов и tabular-чисел (`fontFeatureSettings: '"tnum"'`).
- **Instrument Serif** (`400`, italic) — `var(--font-serif)`, через токен
  `serif`. Только акцентный курсив в Hero-блоках лендинга. Не
  использовать как основной шрифт.

Базовый `letter-spacing` для body — `-0.01em` (выставлен на `<body>`).
Не дублировать в стилях.

### Типографика — каноническая шкала

| Случай                      | Mobile | Desktop | Weight | Line-height | Letter-spacing |
| --------------------------- | ------ | ------- | ------ | ----------- | -------------- |
| Главный hero (`Hero` лендинга) | 44   | 68      | 700    | 1.02        | -0.035em       |
| Page hero (`PageHero`)      | 40     | 64      | 700    | 1.02        | -0.035em       |
| Section H2 (`H2`)           | 48     | 48      | 700    | 1.05        | -0.03em        |
| Subsection H2               | 22     | 26      | 700    | —           | -0.025em       |
| Lead paragraph              | 16     | 19      | 400    | 1.55        | inherit        |
| Body                        | 14–15  | 14–15   | 400    | 1.5–1.65    | inherit        |
| Eyebrow / breadcrumb        | 11–12  | 11–12   | 400/600| —           | 0.06–0.1em     |
| Caption / mono              | 9–13   | 9–13    | 400/600| —           | inherit        |

**Правила:**

- Один h1 на страницу.
- Заголовок страницы — всегда `PageHero` (40/64). Не верстать руками.
- Заголовки крупных секций лендинга / тарифов / любого
  длинного маркетингового контента — `H2` (48). Если нужен акцентный
  цветной хвост — через `accent`-prop. Не плодить ручные h2 на 36 / 40
  / 56.
- Подзаголовки внутри секции (например, секции FAQ-страницы или
  название категории внутри списка) — 22/26.
- Lead-абзац под заголовком — 16/19, `color: '#444'` (не `muted`,
  чуть темнее), `maxWidth: 600`.
- Mono-шрифт всегда сопровождается `letterSpacing` от `0.06em`
  (внутренние числа) до `0.1em` (uppercase eyebrow). Без spacing
  он выглядит сжатым.

### Сетка и отступы

- Контентный `maxWidth: 1280`. Внутри секции всегда обёрнут в
  `<div style={{ maxWidth: 1280, margin: '0 auto' }}>` — это уже
  делает компонент `Section`.
- Горизонтальный padding страницы:
  - Mobile (≤767): `20px`.
  - Desktop: `48px`.
- Вертикальный padding секций:
  - Стандартная секция: `120px 48px` desktop / `64px 20px` mobile.
  - Page hero (между navbar и первой секцией): `40px 48px 0` desktop /
    `24px 20px 0` mobile, нижний padding делается на внутреннем
    блоке (`56` / `40`).
- Отступы между секциями — за счёт `borderTop: 1px solid SUB0.line`
  на следующей секции (в компоненте `Section`).
- Внутри grid-сеток — gap `32` mobile / `64–72` desktop. Не выдумывать
  значения вне этой шкалы.

### Mobile breakpoint

Один-единственный — **768px**. Хук `useIsMobile()` в
`shared/hooks/use-is-mobile.ts`. Использовать только его, никаких
`window.innerWidth` руками. Хук синхронен через `useLayoutEffect`,
чтобы не было flash-перерасчёта.

Никаких других breakpoints (`sm` / `md` / `lg`) — их нет. Если на
конкретной странице нужен промежуточный — обсудить и добавить хук
с явным именем (`useIsTablet`), а не плодить `matchMedia` инлайном.

### Page hero (страницы кроме главной)

Любая внутренняя страница (`/pricing`, `/faq`, будущие `/blog`,
`/roadmap` и т.д.) **обязана** начинаться с `PageHero`:

```tsx
<PageHero
  breadcrumbs={[{ label: 'Главная', href: '/' }, { label: 'FAQ' }]}
  title="Вопросы и ответы"
  description="…"
/>
```

Внутри: cream-фон, grid-фоновая решётка с radial-маской, mono
breadcrumbs uppercase, h1 40/64, lead 16/19. Размеры/шрифты не
менять без обновления этого файла.

Главная страница использует свой `Hero` (44/68 + serif accent +
живой mock дашборда) — это маркетинговый обложечный блок, не
шаблонный page hero. Он намеренно **крупнее** обычного заголовка.

### FAQ accordion

Любой список вопросов-ответов — через `FAQAccordion`:

```tsx
<FAQAccordion items={items} defaultOpenIndex={0} />
```

Используется на `/`, `/pricing`, `/faq`. Если фон секции отличается
от cream — передать `closedButtonBg`, чтобы кнопка `+/–` оставалась
контрастной (по умолчанию `SUB0.bg`).

Размер вопроса — 15/18 по умолчанию. На странице `/faq` (вопросы
сгруппированы по 3 секциям) — 15/17 для визуальной иерархии
относительно H2 категории.

Не копировать accordion-разметку в новых местах. Если нужна
другая логика (например, multi-open) — расширить `FAQAccordion`
проп-ом, а не форкать.

### Хлебные крошки

Только внутри `PageHero` через проп `breadcrumbs`. Mono-шрифт,
uppercase, 12px, разделитель `/` с `opacity: 0.5`. Последний
элемент — `ink` + 600, без ссылки. Все остальные — `muted`,
href обязателен.

### Кнопки (стандарт)

- Primary CTA: `background: SUB0.ink`, `color: SUB0.bg`, `borderRadius: 999`,
  `padding: 10px 16px`, `fontSize: 14`, `fontWeight: 600`. Класс
  `s-btn` для hover-приподнимания.
- Secondary: `background: SUB0.panel`, `border: 1px solid SUB0.line`,
  `color: SUB0.ink`, остальное как primary.
- Inline-кнопка (toggle, аккордеон) — без бэкграунда, padding по
  контексту. Open-state — `background: SUB0.blue`, `color: '#fff'`.
- Стрелка `→` в конце CTA — норма.

### Ссылки

- Все навигационные ссылки на маршруты Next.js — **`next/link`**, не
  `<a>`. Это касается header, footer, hero CTA, breadcrumbs.
- Hash-ссылки (`#dashboard`) и mailto/tel — `<a>` ок. Hover —
  через класс `s-a` (`opacity: 0.7` на hover). Внутри Link —
  тоже можно вешать `className="s-a"`.
- Логотип / иконка в header — **всегда** `Link href="/"`. Никаких
  `#top` и других способов скролла к началу страницы.

### Карточки и тени

- Карточка: `background: SUB0.panel`, `border: 1px solid SUB0.line`,
  `borderRadius: 12–16` (в зависимости от размера контента),
  `padding: 20–32`.
- Hover на карточках: класс `s-card` — `translateY(-2px)` +
  `border-color: #d6d2c5` + лёгкая тень. Не плодить кастомные
  hover-эффекты.
- Тени в основном тонкие и редкие (`0 10px 24px -16px rgba(10,10,10,.2)`),
  больших drop-shadow в макете нет.

### Анимации

В `globals.css` уже есть keyframes: `s-pulse`, `s-float`, `s-spin`,
`s-blink`, `mega-drop-in`. Использовать их, новых не добавлять без
явного требования. `transition: .15s` — стандартная длительность
для hover/active.

### i18n

Все строки идут через `useLang().t(ru, en)`. Захардкоженной
кириллицы / латиницы в JSX не должно быть, кроме брендовых имён
(`Sub0`, `JetBrains`, имени домена). См. `ctx-frontend-fsd.md` § i18n —
ключи через `next-intl` появятся в v1.1, до этого пользуемся
inline-функцией `t`.

### Что **не** делать

- Не вводить новые цветовые значения. Только токены `SUB0.*`.
- Не вводить новые размеры заголовков. Только шкала выше.
- Не дублировать accordion / hero / секцию — рефактор в shared.
- Не использовать Tailwind / CSS-modules / styled-components —
  весь стиль — inline-стили + минимальный `globals.css` для keyframes
  и hover-классов.
- Не добавлять новые breakpoints без обсуждения и обновления
  этого файла.
- Не использовать `<a>` для маршрутов Next.js.
- Не ставить `letterSpacing` на каждом узле — `body` уже задаёт
  `-0.01em` глобально.
